# Диспетчерская 3D

Живой прототип к кейсу «Диспетчерская: замена сломанного автобуса».

Сценарий: на маршруте №10 сломался борт 4412. Выберите резерв, посмотрите его путь по улицам и назначьте на маршрут.

- 2D · работа / 3D · обзор — переключатель в верхней панели
- светлая и тёмная тема — кнопка рядом с часами
- колесо или щипок — масштаб, перетаскивание — поворот (в 2D — сдвиг)

Одна статическая страница: `index.html` + `three.min.js` (three.js r147, MIT). Сборка не нужна.

Все данные вымышленные.
