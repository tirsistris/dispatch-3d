# Диспетчерская

Живой прототип к кейсу «Диспетчерская общественного транспорта» на baatr.vercel.app.

Три режима одного продукта:

- **Смена** (`index.html`) — рабочий экран диспетчера из Figma (страница «v3 · Рабочий экран»): маршруты → рейсы → борт, лента интервалов, карта. Сценарий по шагам: смена 14:28 → авария В 412 КО → выбор и назначение резерва → телефон водителя «Принял» → разбор в журнале. Подложка карты — данные OpenStreetMap, нарисованные в цветах дизайн-системы. `?step=0…4` открывает нужный шаг.
- **Карта района** (`map.html?mode=2d`) — обзор района: очередь инцидентов, сводка смены, лента интервалов. Собран на первой версии экранов, номера бортов — гаражные (4412 = В 412 КО).
- **3D** (`map.html`) — тот же сценарий замены на объёмной карте; для разбора, видеостены и старшего смены.

Светлая и тёмная тема (кнопка в меню слева или у часов). Сборка не нужна: статические страницы + `three.min.js` (three.js r147, MIT).
