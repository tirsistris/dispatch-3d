# Диспетчерская 3D

Живой прототип к кейсу «Диспетчерская: замена сломанного автобуса».

Сценарий: на маршруте №10 сломался борт 4412. Выберите резерв, посмотрите его путь по улицам и назначьте на маршрут.

- 2D · работа — рабочий экран диспетчера из Figma (экраны 00–03), собранный в HTML/CSS на токенах файла: уведомление → панель замены → назначено
- 3D · обзор — тот же сценарий на объёмной карте района; выбор и назначение резерва общие для обоих режимов
- светлая и тёмная тема — кнопка рядом с часами
- колесо или щипок — масштаб, перетаскивание — поворот (в 2D — сдвиг)

Одна статическая страница: `index.html` + `three.min.js` (three.js r147, MIT). Подложка карты 2D — растр компонента карты из Figma (`map-dark.webp`, `map-light.webp`, 2×), всё поверх неё — живая вёрстка. Сборка не нужна.

Все данные вымышленные.
